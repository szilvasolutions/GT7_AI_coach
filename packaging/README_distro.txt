GT7 AI Coach
============

This is the Windows binary distribution.

1. Unzip this folder somewhere you have write access (e.g.
   C:\\GT7Coach\\). Don't put it inside Program Files — the in-app
   updater needs write access to the install folder.

2. Make sure your PS5 is on the same Wi-Fi / Ethernet network as this
   laptop, and start a race in Gran Turismo 7 (Sport, Championship,
   or Time Trial — not the menu).

3. Double-click GT7Coach.exe.

   On first launch Windows SmartScreen may warn about an unknown
   publisher. Click "More info" then "Run anyway". (Code-signing is
   on the roadmap.)

4. Use the Tools > Configure menu to pick an LLM provider and paste
   your API key once. Then click Start.

For source / docs:  https://github.com/szilvasolutions/GT7_AI_coach
